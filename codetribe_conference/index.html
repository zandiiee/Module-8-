Welcome to the Codetribe Conference 2026

CodeTribe Conference is a technology-focused event that brings together students, developers, innovators, and technology enthusiasts.

The conference provides an opportunity to learn about the latest developments in technology, explore new ideas, build valuable skills, and connect with others in the tech community.

Attendees can participate in talks, workshops, and discussions covering topics such as Web Development,

Artificial Intelligence, and Software Development.

Conference Topics



Artificial Intelligence

Discover how Artificial Intelligence is changing the way we work, learn,and solve problems.

Learn about AI technologies, machine learning, automation, and how developers can use AI to create innovative solutions.

Software Development

Learn about the software development process, from planning and designing to coding, testing, and deployment. Explore programming practices and tools that help developers create reliable and user-friendly software.

Web Development

Web development is the process of creating and maintaining websites and web applications. At the CodeTribe Conference, attendees will learn how technologies such as HTML, CSS, and JavaScript are used to build modern, responsive, and user-friendly websites.
